# Дипломный проект. Часть 2 — API-тестирование Stellar Burgers

## Описание проекта

Автоматизированное тестирование API учебного сервиса Stellar Burgers.

**Адрес тестируемого сервиса:** https://stellarburgers.education-services.ru/

Тесты написаны на Python с использованием `pytest`, `requests` и `allure-pytest`.

Для тестирования используются позитивные и негативные сценарии. Тестовые пользователи создаются с уникальными данными и удаляются после выполнения соответствующих проверок.

## Реализованные проверки

### 1. Создание пользователя

- Успешная регистрация уникального пользователя.
- Повторная регистрация уже существующего пользователя.
- Регистрация без обязательного поля `email`.
- Регистрация без обязательного поля `password`.
- Регистрация без обязательного поля `name`.

**Всего: 5 тестов.**

### 2. Авторизация пользователя

- Успешная авторизация существующего пользователя.
- Авторизация с неверным `email`.
- Авторизация с неверным `password`.

**Всего: 3 теста.**

### 3. Создание заказа

- Создание заказа с авторизацией и ингредиентами.
- Создание заказа без авторизации с ингредиентами.
- Создание заказа без ингредиентов.
- Создание заказа с неверным хешем ингредиента.

**Всего: 4 теста.**

Общее количество автоматизированных проверок — **12 тестов**.

## Используемые технологии

- Python — язык программирования.
- pytest — запуск и организация автоматизированных тестов.
- requests — отправка HTTP-запросов к API.
- allure-pytest — формирование результатов тестирования для Allure.

## Структура проекта

- `tests/test_create_user.py` — тесты создания пользователя.
- `tests/test_login_user.py` — тесты авторизации пользователя.
- `tests/test_create_order.py` — тесты создания заказа.
- `conftest.py` — фикстуры pytest для подготовки тестовых данных.
- `helpers.py` — генерация уникальных данных пользователей.
- `urls.py` — базовый URL и адреса API.
- `requirements.txt` — зависимости проекта.
- `.gitignore` — исключения для Git.
- `README.md` — описание проекта и инструкция по запуску.

## Установка зависимостей

Для установки необходимых библиотек выполнить:

```bash
python -m pip install -r requirements.txt
```

## Запуск тестов

Для запуска всех API-тестов выполнить:

```bash
python -m pytest tests/ -v
```

## Формирование результатов Allure

Для запуска тестов с сохранением результатов Allure выполнить:

```bash
python -m pytest tests/ -v --alluredir=allure-results --clean-alluredir
```

Результаты сохраняются в папке `allure-results`.

Для просмотра HTML-отчёта при установленном Allure Commandline можно выполнить:

```bash
allure serve allure-results
```
